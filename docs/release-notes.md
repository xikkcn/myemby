### 这个版本做了什么

#### 📱 手机端彻底重做

之前手机端基本是「桌面版缩小」，一屏只放得下 1～2 张海报，筛选器文字还会被截断。这一版换了骨架：

- **底部导航栏**：首页 / 媒体库 / 直播 / 我的
- **顶栏精简**：只留 Logo 与服务器切换
- **海报三列网格**：首屏能看到的内容多了一倍
- **筛选器换行**：搜索框独占一行，筛选项自动两列排布，不再被裁掉
- **播放页全屏沉浸**：播放时不套外壳

#### 👆 手机播放手势

- **单击**：暂停 / 继续
- **双击左侧 / 右侧**：后退 / 前进 10 秒
- **左右滑动**：拖动进度（画面中央实时显示时间）
- **左侧上下滑动**：调亮度
- **右侧上下滑动**：调音量

#### 📺 电视端拆分 64 位 / 32 位

老电视盒子多为 32 位 ARM，装 64 位包会**直接安装失败**；新盒子装 32 位包又浪费性能。
这一版把电视端拆成两个包：

| 文件 | 适用 |
| --- | --- |
| `myemby-v1.0.2-tv-arm64.apk` | 64 位电视 / 盒子（推荐） |
| `myemby-v1.0.2-tv-arm32.apk` | 32 位电视 / 老盒子 |

另有对应的 `legacy21` 版本供 Android 5.0 老系统使用。
电视端**与手机端使用不同包名**，同一台设备可同时安装、互不覆盖；锁横屏、应用名显示 `myemby TV`。

#### 🚀 网络加速真正落到日常使用

- **开机自动加速**（新增）：打开开关后，启动 myemby 会自动沿用上次的节点开启加速。
  电视用户很少主动进设置页，这个开关能省掉每次开机手动开代理。
- **电视端扫码配置**（保留）：电视显示二维码，手机扫码打开局域网网页，粘贴节点或订阅即可。
- **只加速 myemby 自身**：不动系统其他软件，你自己的内网 Emby 地址自动直连。

#### 📡 新增：直播（IPTV）

导入 M3U / TXT 频道表，自动分组、搜索、收藏，支持 HLS 播放，电视端可用遥控器换台。

#### 💬 新增：弹幕

播放时按片名自动匹配弹弹Play 弹幕并叠加显示；可调透明度、字号、显示区域；
接口地址与 AppId / AppSecret 可自定义，方便接兼容服务。

#### ☁️ 新增：文件源（WebDAV）

连接 Alist / 群晖 / 飞牛等 WebDAV，浏览目录并直接播放里面的视频，支持断点续播。

### 升级说明

- 桌面端与网页端：直接覆盖，配置与登录状态保留。
- **安卓手机端**：包名未变，可覆盖安装。
- **安卓电视端**：包名由 `com.myemby.app` 改为 `com.myemby.app.tv`，从旧版升级需**先卸载旧版**再装新版。
  好处是此后电视版与手机版可以共存，互不覆盖。
- 安卓签名与 v1.0.1 一致，可正常覆盖安装。

### 已知限制

- Linux 的 AppImage / deb 需要 Linux 环境构建（Windows 无法交叉编译）。仓库自带 GitHub Actions 工作流，
  在 Actions 里手动运行一次即可产出这两种格式。
- 网页版依赖浏览器解码能力，高码率或特殊编码的片源建议用桌面端 / 电视端。
- 网盘（夸克 / 115 / 天翼等）与 SMB 需要原生协议栈，当前架构下暂不支持。
