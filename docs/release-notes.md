### 这个版本新增了什么

#### 🔌 内置网络加速

远程 Emby 服务器速度慢、播放老是卡？现在我的EMBY 里自带加速，不用再另外装代理软件。

- **双核心**：内置 **Xray** 与 **sing-box**，协议覆盖
  `VMess` / `VLESS` / `Trojan` / `Shadowsocks` / `Hysteria2` / `TUIC` / `SOCKS5` / `HTTP`
- **两种导入方式**：直接粘贴订阅链接（支持一键更新），或粘贴节点分享链接（可多行）
- **一键测速**：批量测所有节点的延迟，绿色快、红色慢，一眼挑最快的
- **只加速自己**：只让 myemby 的流量走代理，
  **不影响系统里其他软件**；你自己的内网 Emby 地址会自动直连，不会被绕进代理
- **电视端扫码配置**：电视盒子没摄像头也没关系 ——
  电视上显示二维码，用手机扫码打开一个局域网网页，粘贴节点后点提交，电视立刻导入生效，
  **全程不用遥控器打字**

#### 📺 Android TV 端独立成包

- TV 端从手机包里**拆出来单独发布**：应用名显示为 `myemby TV`
- **强制横屏**，不会因为盒子误判而竖过来
- 针对遥控器做了方向键焦点导航

#### 🐛 其他

- 界面细节打磨，修复若干小问题
